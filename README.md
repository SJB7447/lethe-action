# LETHE 2D 액션 (가제) — 1단계 조작감 실험실

레테 세계관의 이단아가 적의 찢긴 기억을 록온해 연쇄로 파고드는 2D 액션의 프로토타입입니다.
지금은 **손맛 검증** 단계입니다. 그림은 전부 임시 사각형입니다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 표시된 주소(기본 http://localhost:5173)를 엽니다. `main`에 푸시하면 GitHub Pages로 자동 배포됩니다.

## 조작
| 동작 | 키보드 + 마우스 | 패드 |
|---|---|---|
| **시선** (록온·바늘 방향) | 마우스 이동 | 오른쪽 스틱 |
| 이동 | ←→ / A D | 왼쪽 스틱, 십자키 |
| 점프 (길게 누르면 높이) | Space / Z | A |
| 대시 (무적, 8방향) | Shift / X | B / RT |
| 공격: 조각이 열려 있으면 파고들기, 아니면 바늘 | 왼쪽 클릭 / J / C | X |
| 록온 (누르고 있기, 시선 안의 적만) | 오른쪽 클릭 / K / V | RB / LT |
| 고스트 다이빙 (게이지 가득) | E / F | Y |
| 자동 보조 전환 | T | Select |
| 방 초기화 | R | Start |
| 범위·판정 박스 표시 | ` | — |

## 핵심 흐름
1. 록온 버튼을 누르고 있으면 **이단아의 시선 원뿔 안에 있고 벽에 가리지 않은 적**부터 록온이 차오릅니다 (가까울수록, 회피 성공 직후일수록 빠름).
   마우스·오른쪽 스틱을 쓰지 않으면 시선은 몸이 향한 쪽입니다.
2. 다 차면 **찢긴 기억 조각**(앰버색 다이아몬드)이 열립니다. 열려 있는 동안 공격하면 파고들어 쓰러뜨립니다.
3. 성공하면 근처 다음 적의 조각이 바로 열립니다 → 공격을 이어 누르면 연쇄.
4. 조각을 놓치면 닫히고 적이 빠르게 반격합니다.
5. 타격으로 연결 게이지가 차면 E로 고스트 다이빙(임시 연출).
- 회색 적은 균열이 없는 적입니다. 바늘로만 쓰러뜨릴 수 있습니다.
