# 1단계 조작감 실험실 — 목표와 통과 기준

## 목표
적 3~4마리가 있는 방에서 **록온 연쇄 이동만으로 흐름을 타는 느낌**이 나는지 확인합니다.

## 통과 기준 (초안, 기획자가 수정)
- [ ] 적 4마리 방을 땅에 거의 닿지 않고 연쇄만으로 클리어할 수 있다
- [ ] 처음 하는 사람이 5분 안에 연쇄를 3회 이상 이어 간다
- [ ] 기획자 본인이 "한 판 더"를 자발적으로 3번 이상 누른다
- [ ] 수동 록온과 자동 보조를 각각 해 보고 어느 쪽이 나은지 말할 수 있다

## 튜닝 슬라이더 (기획안의 6종)
| 슬라이더 | 키 | 현재 기본값 |
|---|---|---|
| 록온 시간 | `lockTime` | 0.6s (가까우면 `lockTimeMin`까지 짧아짐) |
| 조각 유지 시간 | `fragmentWindow` | 0.63s |
| 연쇄 탐색 거리 | `chainSearchRadius` | 380px |
| 연쇄 이동 속도 | `chainSpeed` | 1800px/s |
| 히트스톱 길이 | `hitstop` | 0.07s |
| 연쇄 후 관성 유지량 | `chainInertia` | 0.42 |

## 작업 순서
1. [x] 뼈대, 튜닝 패널, 이벤트 버스, 배포 설정
2. [x] 기본 이동 (달리기, 점프, 벽 미끄러짐·벽 점프, 무적 대시, 기억 추출 바늘)
3. [x] 록온 → 조각 열림 → 파고드는 타격, 히트스톱, 화면 흔들림
4. [x] 연쇄 (다음 적 조각 자동 열림, 다중 록온, 관성 유지)
5. [x] 실패 처리 (조각 닫힘 → 적 반격)
6. [x] 연결 게이지와 임시 고스트 다이빙
7. [x] 수동 / 자동 보조 토글
8. [ ] 플레이테스트와 게이트 판정
