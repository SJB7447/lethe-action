# 1단계 조작감 실험실 — 목표와 통과 기준

> **판정: 통과 (2026-11-21, 기획자)** — PR #11 빌드(시선 록온·소리 인식·퍼펙트 연쇄·타격 화면 효과 포함) 기준.
> 다음 단계: `docs/STAGE2.md`

## 목표
적 3~4마리가 있는 방에서 **록온 연쇄 이동만으로 흐름을 타는 느낌**이 나는지 확인합니다.

## 통과 기준 (초안, 기획자가 수정)
- [ ] 적 4마리 방을 땅에 거의 닿지 않고 연쇄만으로 클리어할 수 있다
- [ ] 처음 하는 사람이 5분 안에 연쇄를 3회 이상 이어 간다
- [ ] 기획자 본인이 "한 판 더"를 자발적으로 3번 이상 누른다
- [ ] 수동 록온과 자동 보조를 각각 해 보고 어느 쪽이 나은지 말할 수 있다

## 1단계에서 추가된 것 (처음 계획에 없던 것)
- 이단아 시선(마우스·오른쪽 스틱): 시선 원뿔 안 + 벽에 가리지 않은 적만 록온. 연쇄 중에는 벽 무시
- 적 인식: 시선 원뿔 + 소리(벽에 막힘). 소리 = 앰버 "!", 발각 = 크림슨 "!". 발각 뒤에만 공격
- 퍼펙트 록온: 조각이 열린 직후 공격 → 그 연쇄 동안 화면 안 모든 적 록온 (난이도 손잡이 = 퍼펙트 판정 시간)
- 타격 화면 효과: 확대·카메라 밀림·번쩍임·집중선·터널·가장자리 맥동
