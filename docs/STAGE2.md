# 2단계 — 챕터 1 수직 슬라이스 (회색 박스)

## 목표
기획안 5장의 첫 수직 슬라이스를 **임시 그림(회색 박스)으로 처음부터 끝까지** 플레이할 수 있게 만듭니다.

> 레테 마포점 로비 스테이지 1개 → 컷신 1개 → 균열형 보스 1명 → 정산 화면

1단계가 "손맛이 있는가"를 봤다면, 2단계는 **"그 손맛이 스테이지와 보스에서도 유지되는가, 난이도가 맞는가"** 를 봅니다.
정식 그림은 3단계입니다. 단, 기획안대로 보스 격파 순간과 정산 화면은 3단계 아트의 우선순위로 표시해 둡니다.

## 균열형 보스 (초안 — 기획자 확정 필요)
가칭: **챕터 1 보스 (레테 보안 책임자)**. 이름·외형·대사는 드라마 설정에 맞춰 기획자가 정합니다.

- **약점 균열 3곳**: 몸의 서로 다른 위치에 찢긴 기억 조각. 각각 록온 → 조각 → 파고들기. 3곳을 모두 끊으면 **다운** → 큰 피해를 줄 기회
- **페이즈 2개**: 체력 절반에서 패턴이 빨라지고 하나가 추가됨
- 패턴 후보 (조각 타이밍·시선을 방해하는 것 위주):
  1. **기억 소거 파동** — 주기적으로 원형 파동이 퍼지며 닿은 조각을 강제로 닫음. 파동 전에 치거나, 파동이 지나간 뒤 다시 록온
  2. **시선 교란** — 화면에 노이즈 장막. 그동안 이단아 시선 원뿔이 짧아짐
  3. **보안 요원 호출** — 균열 있는 요원을 부름. 요원 → 보스 약점으로 이어지는 연쇄 재료 (퍼펙트 연쇄면 화면 전체를 쓸어 담을 수 있음)
  4. **돌진 / 내려찍기** — 공격 예고 후 큰 공격. 대시로 회피 성공 시 록온 단축 보너스
- 고스트 다이빙: 보스 다운 중 사용하면 큰 피해 (게이지를 보스전까지 아끼는 판단을 만듦)
