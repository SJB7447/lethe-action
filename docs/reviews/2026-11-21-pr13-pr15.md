새 `.clear-overlay`에 표시 우선순위가 없고, DOM에서도 `.help`보다 먼저 배치된다. 기본 도움말이 그 위에 그려지며, 기존 튜닝 패널은 z-index 10으로 HUD보다 위에 남는다. `stage:clear` 구독도 이 패널을 숨기거나 순서를 조정하지 않는다.

| 요소 | 화면 영역 (px) | 결과 |

| 클리어 카드 | x=225, y=151, w=510, h=238 | 중앙 정산 화면 |

## PR #15 — 임시 글자 제거

검토 범위에서 **고유 변경으로 인한 새 결함은 발견하지 못했다.** 아래 위치는 `317b6ba` 기준이다.

- `src/scenes/LabScene.ts:72–75`에 `room:enter`의 카메라 snap 처리만 남긴다. 삭제한 것은 임시 Text 객체·그 타이머·정산 문자열 구독이며 Sim이나 HUD 이벤트를 삭제하지 않는다.

- 통합 사본에서 R5 클리어 시 기록 카드가 표시되고 R 재시작 시 제거됐다. 사망 뒤 재시작하면 사망 오버레이가 사라지고 체력칸은 5개로 회복됐다.

- 시뮬레이션 전 포인터 동기화와 렌더 전 `preRender()` → 포인터 동기화 → 안내 갱신 순서(`:99–109`)도 유지된다.
- H14-1은 Phaser Text를 제거해도 남는 HUD 계층 문제이므로 PR #15 고유 결함으로 중복 집계하지 않았다.
